YouTube Data API Integration

A private tool run by a single operator (Kevin Dean Lüken) to manage one YouTube channel, Keruzā: it uploads the operator's own videos with their titles, descriptions and tags, and reads the channel's own statistics (views, watch time, subscribers) so the operator can see how the content performs.

It is not offered to the public and has no other users. It uses YouTube API Services.
