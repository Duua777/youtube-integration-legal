Privacy Policy

Last updated: 12 October 2026

"YouTube Data API Integration" (the "App") is a private tool operated by Kevin Dean Lüken (the "Operator") for the Operator's own YouTube channel. The App uses YouTube API Services. By using the App you also agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data the App accesses

With the Operator's explicit consent (Google OAuth), the App accesses only the Operator's own YouTube channel: channel and video information (titles, descriptions, tags, privacy settings, publication dates), public and private statistics for that channel (views, watch time, likes, comments, shares, subscribers gained and lost, audience retention), and it can upload videos, thumbnails and captions to that channel and edit their metadata. It does not access any other person's account, and it does not read private messages or watch history.

How the data is stored and used

The data is stored only in a database on the Operator's own computer and is used only to show the Operator how the channel performs and to publish the Operator's own content. It is not sold, not shared with third parties, not used for advertising, and not used to profile anyone. The App uses no cookies and no tracking. The OAuth refresh token is stored in a local configuration file on the Operator's computer and nowhere else.

Keeping data current; retention

Statistics are refreshed from YouTube daily, and the App checks that stored videos still exist. Access is re-confirmed with every refresh. Stored YouTube data is deleted on request, and in any case no later than the periods required by the YouTube API Services Developer Policies after access is revoked.

Revoking access and deleting data

Access can be revoked at any time at security.google.com/settings/security/permissions. After revocation the App stops accessing the channel and the Operator deletes all stored YouTube data obtained through it, within 30 days at the latest. You can request deletion of any data stored about you by contacting the Operator; it will be deleted within 7 days. Deleting the App's copy does not delete anything on YouTube.
